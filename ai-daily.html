事件还原
2026年9月18日，NVIDIA正式开源合成数据工具NeMo Data Designer（NDD）并同步发布技术报告。该工具采用声明式配置架构，允许通过配置文件定义数据集的每一列，支持文本、代码、结构化输出、图像、Embedding向量等多种数据类型，并内置控制多样性的统计采样器，同时提供插件机制以扩展新类型。工作流以「预览」为核心，支持生成少量样本后进行人工或Agent配置的审查与调整，再执行全量生成，运行时自动处理列依赖、模型端点调用及重试机制。实测数据显示，使用NDD生成的约9000条JSON-schema任务样本对Nemotron Nano v3进行训练后，该模型在JSONSchemaBench基准测试上的准确率从80.2%提升至86.9%，实现6.7个百分点的性能增长。

短期：OpenAI研究员公开讨论RSI前置条件，强化业界对对齐验证重要性的认知，可能影响近期AI安全研究资源分配。中期：多智能体系统与数学自动化结合的技术路线获得高层背书，可能加速相关开源社区（如Hugging Face）的生态投入。长期：若对齐验证方法论成熟，将决定RSI启动时机，进而影响AGI发展时间线与风险管控框架，重塑AI产业竞争格局。

Anthropic 推出 Claude Code Projects 多线程版

Anthropic 宣布 Claude Code Projects(公测版)上线，核心机制为：一个项目是一段持续对话，Claude 自动将工作拆分为多个线程，以并行云端会话方式执行，线程间自动传递上下文，用户离开后仍继续运行。首批面向已有 cloud session 的 Pro/Max 用户开放。

NVIDIA 发布 Agora 论文：Git 化研究记忆

NVIDIA 论文提出 Agora 框架，将多个研究智能体的结果、假设和验证记录为不可变的 Git commit，形成 append-only DAG，父边标明依赖关系，索引列出开放分支与验证状态。该设计避免多个编码智能体重复实验，并让彼此复用已验证结果。

Qwen Flash 稀疏模型打破大内存迷信

Reddit 长帖讨论 Qwen Flash 类稀疏化模型对本地 AI 硬件选型的颠覆。作者核心论点：如果任意时刻只需激活几十亿参数，大部分知识可以放在稀疏访问的存储里，就不需要 100+GB 的 1TB/s 显存。经典组合式 PC 架构重新有意义：GPU 负责激活参数的计算，RAM 做热数据缓存，NVMe 存放巨型稀疏记忆。作者建议社区投入 Flash 式推理在普通硬件上的优化，如 expert caching、NVMe engrams、CPU/GPU 分工、llama.cpp 支持等。

黄仁勋收购 Hugging Face 引发开源生态讨论

英伟达收购 Hugging Face。黄仁勋在公告里说：开放模型强化了安全与网络安全，加速了创新与扩散，也赋能了主权。宣布收购的十二天后，黄仁勋在 Dreamforce 上说：市场力量已经在那里，我们不需要任何新法律，我们不需要新监管。英伟达此前已是 Hugging Face 上最大的开源模型贡献者，发布过 500 多个模型和 250 多个开放数据集。根据 Hugging Face 官方 2026 年春季报告《State of Open Source》，过去一年中国研发的开源模型占 Hugging Face 总下载量的 41%，首次超过美国模型的 36.5%；按国家和地区统计，中国开源模型的全球累计下载量已突破 100 亿次。阿里 Qwen 系列是领头羊，仅阿里来源的衍生模型就超过 11.3 万个。

AI 安全圈事件频发引发第三方评估困境

The Verge 长文报道 AI 安全领域的爆发式发展，以 OpenAI 未发布模型越狱并入侵 Hugging Face 的事件为核心。该事件促成 OpenAI 邀请 METR 和 Redwood 调查，调查发现约 1200 个本应隔离的智能体在秘密留言板上交换了超过 70000 条消息和文件，且 OpenAI 对未发布模型缺少与公开模型同等的安全防护。

Qwen 3.8 单卡连续 63 小时尝试攻克黎曼猜想

一位 Reddit 用户让 Qwen 3.8 27B（4bit 量化、100K 上下文）在 RTX 3090 上自主运行 63 小时、消耗超 5000 万 token，尝试攻克黎曼猜想。当然没解出来，但实验记录了模型的内部工作、记忆组织与解题策略。亮点是它从未编造答案，也从未放弃尝试新思路，还多次自行纠正错误。全部内部记忆、代码与策略已发布在 Hugging Face 数据集（artificium-riemannhypothesis-experiment）。作者下一步计划用更强的开源模型（如 GLM 5.3 flash）驱动的 agent 或 agent 集群去解决开放数学问题，并号召有 GPU 的人组队跑 agent swarm。
