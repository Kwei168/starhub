短期：Anthropic通过分阶段灰度发布确保Pro/Max高净值用户的稳定性，缓解服务器负载压力，同时确立当前云端多代理协作的标准范式。中期：本地环境支持的缺失与Team/Enterprise版的滞后，意味着企业级深度部署仍需等待，但并行云端执行将显著提升开发者在复杂重构任务中的时间效率。长期：从单会话工具向自主多线程云端工作模式的演进，标志着AI编程助手从辅助编写代码向独立承担长周期项目管理的范式转移，削弱了对本地算力持续在线的依赖。

事件还原
2025年至2026年9月，Rhodium Research发布数据揭示中美AI商业模式差异。OpenAI年经常性收入（ARR）约400亿美元，Anthropic约650亿美元，合计约1050亿美元。同期，中国头部大模型厂商中，字节跳动大模型业务约40亿美元，阿里百炼MaaS约23-24亿美元。数据显示，OpenAI与Anthropic的营收总和约为中国所有AI模型总和的10倍。在开源层面，2025年中国模型在Hugging Face累计下载量超20亿次，占平台总下载量的41%，但用户可自行部署或通过第三方访问，导致收入难以回流至原始开发者。

影响分析
短期：中美AI商业体量差距具象化，验证封闭API模式在B端付费上的效率优势，中国开源社区面临‘叫好不叫座’变现困境。中期：促使国内厂商调整战略重心，从单纯堆砌开源模型转向探索企业级SaaS服务或混合云部署，以弥补纯开源模式的收入短板。长期：全球AI开发范式将趋于分化，美国主导高价值闭源生态，中国主导开源分发网络，但需突破技术红利向商业红利的转化壁垒。

信源分歧
各源报道角度一致。Rhodium、CNBC及AGI Hunt均引用同一组核心数据，侧重客观呈现中美营收差距及开源模式对变现的制约，无观点分歧。

Anthropic合并Claude Chat与Cowork并推出新品

Anthropic将Claude Chat与Claude Cowork合并为统一体验，同时推出Claude Docs和Claude Slides（目前为测试版），此前发布的Claude Design也一并并入对话界面。输出可导出为PowerPoint、PDF或Google Docs、Word格式。新体验先向Pro和Max订阅用户推送，未来几周覆盖网页、桌面和移动端，Team和Free计划随后跟进。历史对话、Skill、连接器全部保留，跨入口通用。

Claude Code Projects线程云端运行机制详解

根据Claude Code官方文档，每个线程都是云端运行的Claude Code session，即使电脑离线也持续工作。本地工作流支持被标注为“即将推出”。用户可追踪Project-specific usage并选择协调器和worker threads的model及effort level。支持在developer的工具和代码旁运行threads（包括private network后的资源）将在未来推出。目前为Pro/Max公测、逐步推送，Team/Enterprise暂不可用。若在claude.ai/code侧边栏或桌面应用Code标签页未看到入口，说明账号尚未被选中。
