事件还原
2026年9月18日，Anthropic 正式宣布在桌面端与网页端推出 Claude Code Projects 功能，目前以测试版（beta）形式向部分 Pro 和 Max 用户的 cloud sessions 开放。该功能的核心机制是：用户在 Claude Code 中发起一次项目对话，描述任务后，Claude 自动将工作拆分为多个并行线程，以并行云端会话方式执行；线程间自动传递上下文，即使用户合上笔记本离开，任务仍在云端继续运行。Anthropic 员工 catwu 表示她每天使用该功能进行批量派发任务，项目带有随使用演化的长期记忆，可随时聚合状态更新。官方计划在随后几周逐步向所有 Claude 用户推送。

影响分析
短期：Claude Code 从单会话工具升级为自主多线程云端工作模式，Pro/Max 用户获得第一批生产力提升，批量派发任务后无需守在电脑前。中期：Projects 功能若验证有效，将推动 AI 编程工具从'对话式辅助'转向'自主执行'范式，竞品如 Cursor、Copilot 需跟进类似能力。长期：云端并行+长期记忆的项目模式可能重塑软件开发工作流，使得复杂任务可跨天持续推进，AI 编码 Agent 的自主性标准被拉高。

信源分歧
各源报道角度一致。AI Hot 7天公开池侧重功能介绍与开放范围；AGI Hunt 补充了 Anthropic 员工 catwu 的日常使用实证及项目长期记忆特性；三个来源在核心机制和开放进度上无分歧，信源交叉验证充分。

后续展望
未来几周面向全量用户推送后，Claude Code Projects 将成为检验 AI 编码自主执行能力的标杆；若长期记忆与并行调度体验良好，Anthropic 有望进一步开放 API 能力给第三方工具调用。

Anthropic 重构 Projects 可能加速消耗订阅额度
