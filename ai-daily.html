2026年8月3日至9月19日期间，Swarms Cloud 发布产品更新日志。此次更新新增了 Auto Agent Builder、Chat、Batch、Grid、Skills 与 MCP 等能力，并重做了 agent 与 completion 页面。核心升级在于推出全链路可观测系统，支持追踪发往 Swarms API 的每一次请求，允许按 agent 名称或 ID 搜索过滤，监控 token 用量与成本，查看完整请求 payload 与输出。同时，平台推出更快的全新仪表盘，覆盖活动、成本、提示词、配置、tokens 等运行细节，旨在便于调试和优化 agent 工作流。

影响分析
短期：降低 Agent 开发者的调试门槛，通过可视化的请求追踪和成本监控，提升现有用户的工作流效率。中期：MCP（Model Context Protocol）的引入表明 Swarms 正在加强与生态工具的互操作性，有助于在开源 Agent 框架竞争中巩固基础设施地位。长期：全链路可观测能力的标准化，可能推动 Agent 运维（AgentOps）成为行业基础规范，促使竞争对手跟进类似的可观测性功能以维持竞争力。
