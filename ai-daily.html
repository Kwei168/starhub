深度解读

事件还原
2026年9月29日，Anthropic 正式发布 Claude 5.5 家族第二款模型 Claude Sonnet 5.5 [1]。作为继 Opus 5.5 之后的第二款产品，该模型定位为主力日常任务模型，官方宣称其运行速度较 Sonnet 5 提升超过 30%，多数任务成本最高降低 30% [8]。定价维持与 Sonnet 5 相同（输入 $2/M、输出 $10/M），但因单任务消耗的 token 数减少，实际支付成本下降 [9]。性能方面，Terminal-Bench 4.0 得分从 10.3% 跃升至 70.6%，超越同家族的 Opus 5.5 [13]。此外，其 Artificial Analysis 智能指数得分为 56，仅落后 Opus 5.5（max）2 分 [9]。同时，Sonnet 5.5 成为 claude.ai 免费层的默认模型 [3]。该模型即日起全量可用，Claude Haiku 5.5 预计在未来几周加入该系列 [10]。

影响分析
短期：Sonnet 5.5 以半价 token 价格提供接近旗舰的性能，迅速替代 Sonnet 5 成为中端主力，对 GPT-6 Sol/Astra 等竞品形成直接价格与性能双重挤压 [5]。中期：凭借 Terminal-Bench 70.6% 的高分及多智能体并发能力，Anthropic 在智能体编码场景确立优势，吸引大量开发者迁移至 Claude Code 生态 [2]。长期：中端模型性能逼近旗舰，可能加速市场向“两端分化”演进——旗舰负责复杂决策，超低价/高频中端模型负责规模化执行，模糊传统中端定位 [33]。

信源分歧
IT之家侧重于分析其智能体编码性能优于 Opus 5.5 的技术原因，即多智能体并发不突破成本上限 [2]。AGI Hunt 中的 Every 团队实测强调其写作能力局部反超 Opus 5.5 [5]。Artificial Analysis 的评测则揭示了争议点：虽然智能指数接近 Opus，但 max effort 下每任务输出约 19.3k token，为所有已测模型最高，约为 GPT-6 Astra 的 7 倍，指出高消耗带来的潜在成本问题 [9]。
