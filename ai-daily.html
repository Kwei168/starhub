近期，SaaS市场出现明显的抛售潮。自2026年1月29日以来，ServiceNow股价累计下跌超22%，汤森路透跌超26%，Intuit跌逾26%，Snowflake跌18%。这一趋势在市场担忧AI Agent技术可能颠覆传统软件商业模式时加速。与此同时，Anthropic官方宣布在桌面端和网页端推出Claude Code Projects（测试版，面向部分用户）。该功能的核心机制是‘一个项目即一段持续对话’，Claude会将需求拆分成多个线程，以并行云端会话的方式执行。线程间自动传递上下文，即使用户离开也能继续运行，并通过跨线程共享记忆构建持续的工作流。这一发布将Claude Code从单会话工具推向了自主多线程的云端工作模式，进一步加剧了市场对Agent替代传统SaaS席位收费模式的恐慌。

影响分析
短期：SaaS巨头股价承压，市场情绪由担忧Agent替代主导，资金从传统企业软件流向AI基础设施板块。中期：Anthropic的并行线程架构可能成为Agent开发新标准，传统SaaS厂商被迫加快集成AI Agent能力或重构定价模式，以证明其在复杂工作流中的不可替代性。长期：若Agent能直接调用CRM、财务和法律工具完成端到端流程，按席位收费的传统SaaS模式将面临结构性挑战，软件行业可能从‘工具订阅’转向‘成果付费’或‘API调用付费’的新范式。

信源分歧
AGI Hunt聚焦于Anthropic的技术创新，报道Claude Code Projects的多线程并行执行机制及上下文传递能力，角度偏向技术演进。摘要部分则侧重资本市场反应，引用ServiceNow、Intuit等具体跌幅数据，并指出市场担忧的核心是Agent对传统SaaS席位收费模式的动摇。两者一偏技术实现，一偏商业影响，形成互补视角。

后续展望
预计Q4将出现更多SaaS厂商与Anthropic等大模型公司合作的消息，以缓解市场对Agent替代的焦虑。

Claude Code Projects 实现断网持续工作的云端并行。

Anthropic 重构 Claude Code 的 Projects 功能：用户设定目标后由 Claude 拆解任务、并行调度多个线程、审查输出并汇总结果，每个线程作为独立云端会话运行，即使电脑离线也持续工作，并支持随时间构建跨线程共享记忆。官方文档说明目前为 Pro/Max 公测，Team/Enterprise 暂不可用，后续将逐步推送至所有用户。
