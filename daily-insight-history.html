2026年9月17日，微软正式发布 Visual Studio Code 1.138 版本。此次更新重点优化了 AI 智能体协作能力，核心新功能包括开发容器内的智能体会话和扩展 Codex harness。在开发容器中，新版支持在本地开发容器内运行智能体会话，智能体可使用项目指定的工具和依赖项，并遵循项目配置的环境，该机制默认不会调用本地计算机中的全部工具和依赖项。启用该功能需安装 Docker 并配置 chat.agentHost.devContainer.enabled 选项，带有受支持开发容器配置的本地文件夹将在菜单中显示'使用开发容器'选项。同时，扩展 Codex harness 支持在 ChatGPT 应用与 VS Code 之间延续同一会话，用户可选择 GitHub Copilot 订阅或 ChatGPT 订阅，若同时登录两类账户，还能在模型选择器中切换模型。

深度解读
事件还原

2026年9月16日，TypeSafe AI正式发布System One模型Jev。该模型由OpenAI前RLHF研究者Diogo Almeida创立并领导研发。与传统大语言模型不同，Jev不生成文本，仅输出Choice、Score、Noul三类结构化决策。在定价策略上，输入词元每百万0.042美元，输出词元免费。另据材料显示，Jev对自然语言问题返回校准的概率判断，宣称响应时间在70至500毫秒之间。

影响分析

短期：低价输入策略将冲击当前LLM推理市场的价格体系，迫使竞品重新评估成本结构。中期：非文本输出模式为自动化决策场景提供新范式，降低Token消耗的同时提升响应速度，可能重塑Agent架构设计。长期：若结构化决策性能得到验证，将推动AI从内容生成向执行层渗透，改变应用层开发逻辑。

信源分歧

AIHOT报道侧重产品发布本身及技术参数，强调不生成文本的特性；原文摘要补充了具体的响应时间数据（70-500ms）及概率判断功能，两者在技术细节上互为补充，无实质性分歧。
