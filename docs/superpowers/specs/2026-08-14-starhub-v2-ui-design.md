# StarHub v2 UI 改版设计文档

日期：2026-08-14
状态：已获用户确认

## 1. 背景与目标

当前页面（GitHub Star 收藏台，Kwei168）存在以下问题：

1. **信息架构主次颠倒**：核心内容「我的收藏」被挤到第三屏，首屏被「每日 AI 排行榜」（20 条全宽）与「今日关注动态」占据；
2. **信息冗余**：排行榜条目塞入 5 类信息，「新上榜」红标 + 红字双重强调；
3. **视觉层级平、配色体系分裂**：排行榜（橙/蓝/绿 tab + 金银铜）与收藏模块（GitHub 蓝 + 11 色分类板）像两个不同网站的皮肤；
4. **宽屏利用率差**：1440px 下「今日关注动态」全宽单列，两侧大片留白；
5. **工具区割裂**：搜索/下拉/星标按钮分两行散放；sticky header 仅放 logo 与 4 个图标按钮，信息承载浪费。

改版目标：收藏列表成为页面主角，排行榜/动态收纳为桌面端侧边仪表盘；整套视觉升级为青蓝渐变品牌风。

## 2. 用户确认的方向决策

| 决策点 | 结论 |
|---|---|
| 布局主次 | 桌面双栏布局：左主（收藏）右辅（排行榜+动态） |
| 视觉风格 | 品牌定制风：深色渐变顶栏 + 品牌主色 |
| 品牌主色 | 青蓝渐变（主色 #0ea5e9，亮色；暗色 #38bdf8） |
| 侧栏排行榜形态 | Top10 + 「查看完整 Top20」全屏浮层 |
| 功能范围 | 全部功能保留，只改 UI（不砍功能、不改数据层） |

## 3. 布局设计（桌面 ≥1100px）

```
┌────────────────────────────────────────────────────────────┐
│ Header：深青蓝渐变品牌顶栏（sticky）                         │
│  logo ｜ 更新时间徽章 ｜ 数据概览 ｜ 视图/主题/导出/导入      │
├──────────────────────────────────────┬─────────────────────┤
│ 主区（收藏，自适应宽）                │ 侧栏（固定 340px，sticky）│
│ ┌ 统计条：4 卡带图标，紧凑化        ┐ │ ┌ 每日 AI 排行榜 ────┐ │
│ │ 语言分布（可折叠面板）            │ │ │ 三 tab · Top10 紧凑  │ │
│ │ 工具栏：搜索｜语言｜排序｜星标 一行 │ │ │ [查看完整 Top20 →]  │ │
│ │ 分类 Tabs（胶囊）                 │ │ └─────────────────────┘ │
│ │ 置顶区 + 全部项目网格             │ │ ┌ 今日关注动态 ──────┐ │
│ │ （3 列卡片，hover 动效）          │ │ │ 紧凑时间线列表      │ │
│ └─────────────────────────────────┘ │ └─────────────────────┘ │
└──────────────────────────────────────┴─────────────────────┘
```

- 侧栏固定宽度 340px，`position: sticky` 跟随滚动；
- 侧栏内部结构：排行榜在上、关注动态在下；
- **双栏断点：≥1100px 双栏，<1100px 单列堆叠**；移动端单列顺序为 收藏 → 排行榜 → 动态（核心优先，与桌面一致）；

## 4. 视觉系统

### 4.1 顶栏（品牌化核心）

- 背景：`linear-gradient(120deg, #082f49, #0e7490, #0891b2)`（深空青蓝渐变），亮暗主题均用深色渐变（暗色主题可加深至 #041e3a 起始）；
- 文字/图标白色，半透明磨砂（`backdrop-filter: blur`）；
- 顶栏内容：logo（保留 GitHub 猫图标，可加渐变光环）、「更新于 YYYY-MM-DD HH:MM」徽章（绿色小胶囊，白色文字）、数据概览（项目总数 · 分类数）、原有操作按钮组（视图切换/主题/导出/导入），按钮改为白底透明化风格（半透明白 + 白描边，hover 增强）。

### 4.2 品牌色与状态色

- 品牌主色：亮色 `#0ea5e9`、暗色 `#38bdf8`；派生 weak 背景（`#0ea5e9` 15% 透明度）用于选中态/搜索聚焦光环；
- 分类语义色板（11 色）保留原值，暗色下维持提亮版本（已有）；
- 排行榜 tab 语义色调整为与品牌协调：涨星榜=青蓝系（`#0ea5e9`）、总星标榜=深蓝（`#2563eb`）、新秀榜=绿（`#10b981`）；暗色各 +100 亮度；
- 星标金色 `#e3a008` 保留（与青蓝互补，用于星标图标、置顶边框、金牌徽章）；
- 金银铜徽章色保留。

### 4.3 组件细节

| 组件 | 变更 |
|---|---|
| 统计卡 | 4 卡带主题色图标、数字加大（24→26px）；整体高度紧凑 |
| 语言分布 | 保留彩条+legend，包装为可折叠面板（默认展开），标题行「语言分布 · 共 14 种」带展开/收起箭头 |
| 工具栏 | 单行布局：搜索框（flex:1）｜语言下拉｜排序下拉｜星标分段按钮；控件高度统一 40px；移动端换行 |
| 分类 Tabs | 保持胶囊样式与现有交互（点击切换/再点取消） |
| 项目卡片 | 圆角 14px、hover 上浮 2px + 青蓝描边；分类 tag、今日更新徽章、展开按钮交互全部保留 |
| 排行榜条目（侧栏） | 每条收敛为：排名徽章 + 名称 + 语言圆点 + 理由/星星（四要素）；删除条目内重复描述与「新」红标+红字双重强调（仅保留一处上榜标识，颜色用 tab 主题色） |
| 完整榜浮层 | 全屏遮罩（rgba 半透明，点击关闭）+ 居中面板：标题、三 tab、Top20 完整条目（含描述）、Esc 关闭；淡入上滑动画 300ms |
| 关注动态 | 保持时间线列表结构，条目更紧凑；宽屏下不再全宽 |
| 空状态 | 保留现有交互（提示 + 清除所有筛选按钮） |

### 4.4 字号与层级

- 标题阶梯：区块标题 15px 保持，统计数字 26px，卡片项目名 15px；
- 文本色沿用现有 --text/--muted/--faint 阶梯。

## 5. 交互与动效

1. 统计数字 count-up 动效（页面加载与主题切换重渲染时触发）；
2. 排行榜浮层：打开淡入+上滑 300ms；关闭（Esc/遮罩/关闭按钮）反向；
3. 卡片 hover：上浮 + 描边高亮（现有基础上微调）；
4. 搜索防遮挡逻辑保留（输入关键词自动清空其他筛选 + 空状态提供一键清除）；
5. 快捷键保留（`/` 聚焦搜索、`Esc` 清空/关闭浮层）。

## 6. 技术约束

- **数据层零改动**：`fetch_and_build.py` 的占位符注入（`__DATA__/__CATS__/__LANGS__/__FAVS__/__UPDATED__/__TRENDING__/__FEED__`）格式不变；
- 改动范围：`template.html`（CSS + 结构 + JS 渲染逻辑中涉及 DOM 结构的部分）；改完重新生成 `index.html`（本地跑 `python fetch_and_build.py` 或手动触发 Actions）；
- 保持零依赖：不引入任何外部库/CSS 框架/字体 CDN；
- 明暗双主题完整支持，localStorage 主题记忆与防 FOUC 内联脚本保留；
- 收藏（localStorage）、视图切换（localStorage）逻辑不变。

## 7. 非目标（YAGNI）

- 不做用户系统、后端、数据库；
- 不新增功能模块；
- 不改动分类体系与数据内容；
- 不做多语言切换。
