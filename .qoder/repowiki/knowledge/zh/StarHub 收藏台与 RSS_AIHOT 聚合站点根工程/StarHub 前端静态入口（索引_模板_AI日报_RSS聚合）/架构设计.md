模块由四个并列的单页 HTML 文件组成，无构建工具与框架依赖，样式与逻辑均内联在 `<style>` 与 `<script>` 中：
- `index.html` / `template.html`：StarHub 主索引页，两者 CSS 完全一致；`template.html` 作为可复用模板，DATA/CATS/LANG_COLORS/TRENDING/FEED 等常量以 `__X__` 占位符注入，采用编辑出版风格布局——左侧主内容区 + 右侧侧边栏（trending/feed/aihot 双标签），通过给 `<html>` 设置 `data-theme="dark"` 配合 CSS 自定义属性切换明暗主题。
- `ai-daily.html`：AIHOT 日报静态页面，按 sec-1..sec-5 分节展示卡片墙，顶部导航含分类索引与今日要闻 lead-row 双栏，主题偏好通过 `localStorage('wb_starhub_theme_v1')` 持久化。
- `rss-aggregator.html`：功能最复杂的聚合器，采用“首屏 chunk0 + 后台合并 chunk1”的数据加载策略——`<head>` 中预加载 `rss-data-0.js`，DOMContentLoaded 后先渲染首屏，再在空闲时通过 `loadChunk(1)` 拉取剩余数据并 `_mergeChunk` 去重追加；每 5 分钟调用 `starhub-refresh.vercel.app/api/rss?meta=1` 探测增量更新，有新条目时调用 `/api/rss` 合并。
- 状态管理集中在全局对象：`SOURCES`、`ART`、`filter`、`visited`、`_bookmarks` 等，均持久化到 `localStorage`；视图层按区域拆分为 `renderChips`/`renderWall`/`renderPanel`/`renderReader` 等单一职责函数，通过事件委托统一绑定 `.wall` 点击。
- 全文获取走异步 API `/api/article?url=`，失败时显示行内重试按钮；分享模块基于 Canvas 绘制分享卡片并使用内嵌 `qrcode-generator@1.4.4` 生成二维码；AI 动态流面板聚合 `aihot.virxact.com` 与 `AGI Hunt` 接口。
- 可访问性：所有模态框实现焦点陷阱 `_trapFocus`，并通过 `role="dialog"`、`aria-modal`、`aria-live` 标注。
