本模块为纯静态数据层，无任何可执行逻辑，所有文件通过 HTTP 或本地路径被上层应用直接读取，彼此之间无运行时依赖，仅通过共享 key 在消费端进行关联：
- 仓库元数据：`known_categories.json` 以 `owner/repo` → 类别映射；`descriptions_zh.json` 以相同键提供单行中文一句话简介，供 UI 卡片渲染。
- 公众号源与分析：`bestblogs_sources.json` 维护微信公众号 RSS 源清单（字段 `key/name/cat/url/color/source`），`bestblogs_analysis.json` 按同一 `key` 聚合出 `total/dated/72h/7d/30d/daily_avg/newest/daily_30d` 等预计算指标，供榜单与趋势展示直接使用。
- 榜单快照：`t1_sources.json`、`t2_sources.json` 分别承载 Top 1 与 Top 2 站点源列表，元素为 `[key, name, avg]` 三元组，已按平均热度降序排列。
- 趋势快照：`trending_snapshot.json` 为 GitHub 仓库名到热度分数的字典，作为趋势榜数据源。
- 前端依赖：`vendor_qrcode.min.js` 为第三方 QRCode 库压缩版，由前端页面直接引入生成二维码。
整体结构扁平，数据更新即替换对应 JSON 文件，无需构建步骤。
