- 每个实施任务以「Task N: 标题」+ Files 列表 + Step 子步骤的 checklist 格式编写，便于 agentic worker 逐项勾选推进。
- 每次 Task 提交要求同时提交模板/源文件与生成的 HTML 产物，保持 Pages 入口与模板一致。
- 变更定位精确到文件名与行号范围（如 `template.html:8-25`），并在 Step 中给出替换前后的完整代码块。
- 每个 Task 末尾包含 Run/Expected 形式的本地验证步骤，结合 `dev_render.py` 与 python 结构断言命令。
- commit message 遵循 conventional commits 风格（如 `feat(ui): ...`），因无独立测试文件而统一归入 UI 变更。
- Plan 与 Spec 之间通过文件路径与日期前缀（如 `2026-09-11-llamaindex-insight-engine`）建立一对一映射，确保 plan 始终引用对应 spec 作为权威依据。
