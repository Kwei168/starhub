单文件模块 `insight_engine.py` 以 `run_analysis` 为统一入口，按固定流水线串联五个任务：(1) `configure_llm` 工厂根据配置与环境变量 `AGNES_API_KEY` 选择 `AgnesLLM`（HTTP POST 到 `apihub.agnes-ai.com/v1/chat/completions`，支持多 key 轮询抗 429 限流）或 `MockLLM`；(2) `load_documents` 将多源数据合并为带优先级的文档列表，配额制分配 RSS/Trending/热榜名额，并在缺少依赖时回退到 `_SimpleDoc`；(3) `_build_hierarchical_index` 构建层级向量索引（小索引大窗口：子块检索 + 父文档上下文扩展），通过 `pre_embeddings` 共享同一向量空间，检索改用手动余弦相似度而非 VectorStoreIndex.as_retriever；(4) 辅助函数提供 JSON 解析、余弦相似度、向量平均以及基于字符重叠的 `_fallback_cluster`；(5) `generate_deep_insights` 调用 LLM 生成结构化洞察并以旧格式字段兼容前端。嵌入层支持 SiliconFlow API (`BAAI/bge-m3`) 与本地 fastembed (`intfloat/multilingual-e5-small` / `BAAI/bge-small-zh-v1.5`) 双通道，失败自动回退。RAGAS 风格的评估-修正闭环（`_evaluate_and_correct`）在 `insight_self_correct` 开启时对洞察进行质量评分与自我修正。测试文件 `test_insight_engine.py` 按 Task 1~5 分组为独立 `unittest.TestCase` 子类，使用 `patch`/`MagicMock` 隔离网络与可选依赖。
