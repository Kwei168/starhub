- 可选依赖通过顶层 `try/except ImportError` 捕获并设置布尔标志（如 `LLAMA_INDEX_AVAILABLE`、`FASTEMBED_AVAILABLE`），运行时据此切换功能路径。
- 对外部服务调用（LLM、向量索引构建）均包裹 try/except 并打印错误后返回安全默认值（空字符串、None、[]），保证主流程不中断。
- LLM 抽象采用双实现（`AgnesLLM` 与 `MockLLM`）并通过 `configure_llm` 工厂按配置选择，二者均暴露 `complete`、`stream_complete`、`metadata` 接口。
- JSON 响应统一经 `_try_parse_json` 解析，支持去除 markdown 代码围栏后的容错解析，失败时走 fallback 逻辑。
- 配置集中定义于 `_DEFAULTS` 字典，由 `load_config` 合并用户 `build_config.json` 并 `setdefault` 补齐缺失键。
- 测试用例按 Task 1~5 分组为独立 `unittest.TestCase` 子类，使用 `patch`/`MagicMock` 隔离网络与可选依赖，并通过 `_make_*` 辅助方法构造测试数据。
