模块由 8 个独立的 Vercel Serverless Function 文件组成，每个文件对应一个 HTTP 端点：agihunt.js（代理 AGI Hunt Agent API）、events.js（GitHub 关注账号近 24h 事件聚合）、news.js（多 RSSHub 镜像抓取）、rss.js（T1 实时 + T2/T3 构建时快照混合的 RSS/Atom 聚合）、refresh.js（触发 GitHub Actions workflow_dispatch）、search.js（GitHub 仓库搜索代理）、article.js（网页全文抓取）、translate.js（Agnes AI / Google GTX 翻译兜底）。依赖方向单向向外：所有函数作为“代理”通过 `fetch` 调用上游服务（AGI Hunt、GitHub REST v2022-11-28、RSSHub、任意网页、Google Translate、Agnes AI），不直接访问数据库；数据持久化仅依赖进程内存 Map/{t,v} TTL 缓存及构建产物 rss_sources.json、rss_api_snapshot.json、translations.json。rss.js 采用分层架构：优先返回构建时生成的 rss_api_snapshot.json（72h 累积数据），T1 tier 源实时抓取并写入滚动缓存，T2/T3 源直接从快照合并；article.js 复用同一快照中的 fullContent 字段作为全文兜底。translate.js 按 mode 分流：full 模式以 Agnes AI 为主、GTX 兜底，bulk 模式以浏览器直连 GTX 为主、服务端 GTX + 限量 Agnes 兜底。各函数之间无相互调用，仅共享相同的 CORS 白名单、凭据读取与错误脱敏约定。
