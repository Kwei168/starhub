- 每个函数文件顶部集中声明 ALLOWED_ORIGINS Set，并在 handler 开头统一设置 CORS 头、处理 OPTIONS 预检、校验请求方法是否为 GET/POST。
- 敏感凭据一律通过 process.env.* 读取（GH_TOKEN、AGIHUNT_API_KEY、REFRESH_KEY、AGNES_API_KEY），缺失时返回 500 提示未配置。
- 进程内缓存统一采用 Map 或 { t, v } 结构配合 TTL 时间戳判断过期，达到容量上限时淘汰最旧条目。
- 对外部 URL 访问统一设置 AbortSignal.timeout 超时，并对 fetch 响应做 !r.ok 检查后封装为统一的 { error } JSON 响应。
- 上游失败采用静默降级策略：news.js 依次尝试多个 RSSHub 镜像，rss.js 失败时回滚到滚动缓存，events.js 单个用户失败跳过继续下一批。
- 向调用方返回的错误信息经过脱敏，不直接透传上游 HTTP 状态码和响应体，仅在日志中记录详细错误。
