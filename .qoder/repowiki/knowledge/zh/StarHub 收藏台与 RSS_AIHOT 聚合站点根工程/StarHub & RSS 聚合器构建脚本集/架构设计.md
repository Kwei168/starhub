模块由一组相互协作的独立 Python 脚本组成，围绕两条主线（StarHub 收藏台 + RSS 聚合器）和若干辅助工具：
- 编排入口 `fetch_and_build.py` 是 GitHub Actions 调用的主脚本，拉取 Kwei168 的 starred repos、Trending 涨星榜、关注者事件，按关键词规则分类并翻译简介，注入 `template.html` 生成 `index.html`；并通过 `import build_ai_daily` / `import build_rss_aggregator` 依次调用两个子构建。
- `build_rss_aggregator.py` 维护约 700+ 条 RSS_SOURCES（按 ai/tech/cn_tech/dev/news/podcast/cn_tech_bestblogs 等分类），使用 urllib + xml.etree.ElementTree 抓取 RSS，结合 `translations.json`、`rss_cache.json` 缓存与 `rss_history.json` 72 小时历史累积，输出 `rss-aggregator.html` 及供 `/api/rss` 读取的 `rss_api_snapshot.json`，并对 pub_date 异常信源做自动质量审查。
- `build_ai_daily.py` 从 AIHOT 公开 API v1 为主、RSS feed 降级、再回退到本地 `ai_daily.json`，多渠道抓取 HN/Verge/TechCrunch/arXiv/36氪/Redis/AtlasNote，筛选近 36 小时条目生成报纸风格的 `ai-daily.html`。
- 数据准备工具：`merge_sources.py` 将 BestBlogs 559 个公众号/播客源按 URL 模式分类后合并进 `build_rss_aggregator.py` 的 RSS_SOURCES 并写出 `rss_sources_merged.py`；`extract_bestblogs_sources.py` 用于提取 BestBlogs 源列表。
- 开发/校验工具：`dev_render.py` 从已构建的 `index.html` 反解常量重新渲染 `template.html` 以本地预览模板改动；`check_wiki_sync.py` 断言 Wiki 文档覆盖当前双主线架构事实；`check_html.py`、`_check_fc_format.py`、`_fix_regex.py` 分别检查 HTML 字段中的 img 标签、full_content 段落格式、以及修复嵌入 JS 中正则转义问题。
依赖方向单向：`fetch_and_build.py` → `build_ai_daily.py` / `build_rss_aggregator.py`，其他脚本独立运行或作为 CI 校验步骤，不反向依赖构建产物。
