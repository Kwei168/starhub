根目录作为跨子模块的数据流装配层，将五个子模块串成一条闭环流水线：`.github/workflows/update.yml` 通过 cron（UTC 21:00 全量、其余增量）触发 `python fetch_and_build.py [full|incremental]`，由 `data_and_build_scripts/` 抓取并解析数据后调用 `insight_engine/` 进行 LlamaIndex 语义分析，最终生成 `frontend/` 所需的 `index.html`、`ai-daily.html`、`rss-aggregator.html` 以及 `static_data/` 下的 JSON 快照；`api/` 中的 Vercel Serverless Functions 通过根 `vercel.json` 集中声明路由与 `maxDuration`，对外暴露 refresh/search/events/news/rss/article/agihunt/build_log/translate 等 JSON 接口供前端页面直接消费；CI 在提交后执行 `npx vercel --prod` 完成 Pages/Vercel 部署，形成「抓取→分析→渲染→发布」的端到端链路。根 `package.json` 仅声明 jsdom/@mozilla/readability 两个构建期依赖，所有脚本通过 `node xxx.js` 或 Python 运行，保证前后端与 CI 共享同一份网页/RSS 解析能力。
