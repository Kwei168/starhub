- 对外部资源（GitHub API、翻译服务）访问统一使用 try/except 包裹并在失败时静默降级，确保脚本在网络异常或限流时仍能产出部分数据。
- 项目分类优先查 `known_categories.json`，未命中则回退到 `classify_new()` 基于文件名/描述/topics 的关键词匹配，保持分类稳定且可扩展。
- 中文翻译结果与项目分类分别持久化到 `descriptions_zh.json` 和 `known_categories.json`，下次运行直接复用以避免重复网络请求。
- 时间统一转换为北京时间（UTC+8），通过 `_today_cn()` / `_cn_date()` / `_cn_time()` 工具函数处理 UTC ISO 字符串。
- 前端交互状态（收藏、主题、视图模式）通过 localStorage 键（如 `wb_starhub_favs_v1`、`wb_starhub_theme_v1`）持久化，并提供导出/导入 JSON 备份能力。
- 模板渲染采用字符串 replace 占位符注入 JSON 数据而非模板引擎，保持零依赖、单文件部署。
