- Handler 入口统一以 export default async function handler(req, res) 形式暴露，并在首行根据 Origin 动态设置 CORS 头（Access-Control-Allow-Origin/Methods/Headers/Vary）。
- 对非预期 HTTP 方法直接返回 405 JSON 错误，OPTIONS 预检请求根据来源白名单返回 204 空响应或 403。
- 外部 API 调用失败时捕获异常并以 502 状态码返回包含原始错误的 JSON 对象，成功路径统一以 { ok: true } 或 { error: ... } 的结构响应。
- 敏感凭据（GH_TOKEN、REFRESH_KEY）一律从 process.env 读取，不在源码中硬编码。
